Two or three equal options in a pill track; the Meditation / Study toggle and the sign-in / create-account switch.

- A `radiogroup` of `radio` buttons (or `tablist` when it swaps forms). Arrow keys move the selection.
- Track: `page` fill, `hairline` rim, 4px inset. Options 44px tall.
- Selected: `mana` edge, 12% mana wash, `text-primary`, weight 600. Unselected: `text-secondary`; hover lifts to `text-body` with a faint wash.
- Selection is carried by edge and weight as well as colour.
