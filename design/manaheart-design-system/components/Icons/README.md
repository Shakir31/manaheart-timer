The 28 thin line icons used across Manaheart, drawn inline as SVG.

- 24px grid, 1.4px stroke (1.6 at 18px and below), round caps and joins, no fills, `stroke="currentColor"`.
- Colour: `text-secondary` at rest, `text-body` on hover, `mana` when active (current tab, active category). `error` only for the alert icon.
- Every icon is decorative (`aria-hidden`) unless it is the whole label of a button, which then carries `aria-label`.
- Constellation is reserved for the future third tab; do not use it yet.
- Copy the path data from this card; there is no icon font.
