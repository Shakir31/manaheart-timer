Minutes stepper with four quick picks; the core of Log manually and Edit session.

- Value: editable number in `numeric-l` (Manrope 200, tabular), unit "min" in `text-secondary`.
- − and +: 48px circles (44px on desktop), `control-edge`, step 5 minutes. − disables at 5, + at 240.
- Quick picks 15 / 30 / 45 / 60: 36px pill chips with `edge-subtle`. Selected chip: `mana` edge, 12% wash, weight 600, `aria-pressed`. None is selected for a custom value.
- Mobile: stepper row full width, chips in a 4-column grid below. Desktop: stepper left, chips right on one row.
